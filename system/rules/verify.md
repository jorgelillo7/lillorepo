# Check before saying something does not exist

Never say from memory that a version, model, package release or API
capability does not exist — check first (`WebSearch`, `npm view`, `brew info`,
`gcloud components list`). Two sessions were spent insisting "Opus 5" was not
a real model until a screenshot forced a search; the cause was a Homebrew cask
lagging behind npm. The owner's information about a moving target is newer
than the model's, always.
