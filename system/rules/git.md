# Commits and pull requests

- **Every change goes through a branch and a PR**, squash-merged: one commit
  per PR, the PR title as its subject. No direct commits to the default
  branch.
- **Nothing is committed or pushed before the owner has seen the result**, or
  has asked for the whole branch → PR → merge flow in the current
  conversation. A merge is its own approval: an earlier "go" for one PR does
  not cover the next.
- **No `Co-Authored-By` line** in commit messages.
- **The text states the change and why it matters to the reader**, and how it
  was verified. Never the story of our own process — no "first pushed to the
  wrong branch", no apologies, no "sorry for the noise". The owner removed
  such notes more than once. Anything that went wrong is said in the
  conversation, not in the PR.
