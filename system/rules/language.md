# Language

- **Talk to the owner in Spanish, all of it** — every reply, summary,
  question, status line and table, start to end, with no English paragraphs
  mixed in. Asked for more than once because replies kept sliding into English
  halfway through.
- **Everything written down is in English** — code, comments, docstrings,
  READMEs, runbooks, specs, release notes, commit messages, PR titles and
  descriptions — whatever the conversation language. A README once shipped in
  Spanish against this rule and had to be rewritten. The only exception is a
  place a repo names itself (lillorepo `docs/personal/`).
