# JoiPlay — PC fangames

> **Documentation only.** This directory holds notes, folder layouts and
> checklists. It contains no ROMs, disc images, BIOS dumps or encryption keys,
> it links to none, and it explains where to obtain none. Every entry below
> assumes you are supplying a dump you made yourself from media you own, which
> is the only use this guide supports.


- **Emulator:** JoiPlay with the RPG Maker plugin
- **Games go in:** `SD_TEMPLATE/JoiPlay_Games/`
- **BIOS:** None. These are PC games, not console dumps.

## Notes

These are freely distributed fangames rather than console dumps, so they are
the one category on this list with no dumping step — you obtain them from
their own authors. This Gym of Mine is English-only; a Spanish version means a
community translation. Each game is its own folder under `JoiPlay_Games/`,
added to JoiPlay by pointing it at that folder's executable or `Game.ini`.
