# Wishlist — Release Notes

What changed for whoever opens the list, newest first. 🎁

### **v1.3 - One List for Every Occasion (26 November 2026)**

* **🎉 Ocasión**: from `/admin` you change the title, the subtitle and the look (Christmas red with snow, birthday confetti, or a calm teal), and you rename or switch off each child. A child switched off takes their gifts off the list.
* **🙈 Hide all at once**, then show only what the new occasion needs.
* **🔎 Search by name**: accents and capitals don't matter, and a search can be shared as a link.
* **🏷️ Quieter filter labels.**

### **v1.2 - Filter by Kind, Quicker and Easier to Read (17 November 2026)**

* **🧸 Filter by kind of toy**: cars and tracks, heroes and figures, building and marbles, painting and making, music and stories, home and baby. Only the kinds that child has show, each with how many.
* **⚡ The first photos come first**: the ones on screen when the list opens load at once, the top one ahead of everything else.
* **👓 Easier to read**: the grey text is darker, and text sizes follow the size set on the phone or the browser.
* **🔤 No font from Google**: the title font is served by the list itself, so opening it tells no one else.
* **⌨️ Photo buttons by keyboard**: "Hacer foto" and "Elegir foto" in the admin are real buttons.
* **🔁 Photos kept**: the first list's photos and the font stay in the browser instead of being asked for again.

### **v1.1 - Added From the Shop (12 November 2026)**

A gift used to exist only if someone edited a file and ran a script. Now it is added where the toy is: standing in the shop, from the phone.

* **📱 Gifts from `/admin`**: add, edit, hide and delete a gift, with a photo taken on the spot or picked from the library. Deleting one that somebody already reserved asks first.
* **🧼 A photo never carries where it was taken**: it is cleaned twice — the page redraws it before sending, and the server rebuilds it keeping only the picture — so no location, camera data or anything appended survives.
* **🗃️ The list lives in the database**: the 18 gifts that were there keep their links, their photos and their reservations.
* **🔒 The admin answers only to its own page**: a write must come from the admin page itself, no page can be shown inside another site's frame, and the admin is never cached.
* **🧪 Still to try**: the admin's buttons on a real iPhone, and the first photo stored for real.

### **v1.0 - The List (9 November 2026)**

* **🎄 One list for the family**: photos of the toys, who each one is for, and a button to reserve a gift and mark it bought. Names are optional and only the admin sees them.
